--------------------------------------------------------------------------------
0) BİR KEZ KURULACAK PROGRAMLAR
--------------------------------------------------------------------------------

1. Git
   https://git-scm.com

2. Node.js 20 veya üzeri (LTS)
   https://nodejs.org

3. Docker Desktop
   https://www.docker.com/products/docker-desktop

Docker Desktop'ı aç. Simge yeşil / "Running" olana kadar bekle.
SQL Server bu Docker'ın içinde çalışır. Docker kapalıysa giriş 502 verir.

Kontrol (terminal / PowerShell / Komut İstemi):

    node -v
    npm -v
    docker --version


--------------------------------------------------------------------------------
1) PROJEYİ İNDİR
--------------------------------------------------------------------------------

    git clone https://github.com/rdmrcn/Fathom_OperationSystem.git
    cd Fathom_OperationSystem

FORGE reposunun içindeki fathom klasöründeysen:

    cd fathom


--------------------------------------------------------------------------------
2) PAKETLERİ KUR
--------------------------------------------------------------------------------

    npm install

Bitmesini bekle. Hata olursa Node sürümünün 20+ olduğundan emin ol.


--------------------------------------------------------------------------------
3) ÇALIŞTIR
--------------------------------------------------------------------------------

    npm run dev

Bu komut:
  - .env yoksa .env.example'dan kopyalar
  - SQL Server 2022'yi Docker'da başlatır (port 1433)
  - API'yi http://localhost:4000 adresinde açar
  - Web arayüzünü http://localhost:5173 adresinde açar

İLK SEFERDE SQL imajı inebilir (1–3 dakika). Sabırlı ol.

Terminalde şunu görene kadar tarayıcı AÇMA:

    Fathom API listening

Durdurmak için terminalde Ctrl+C.

--------------------------------------------------------------------------------
5) UYGULAMA NE İŞE YARAR (KISA TUR)
--------------------------------------------------------------------------------

Girişten sonra:

  - Özet (Dashboard)     : SQL Server'dan canlı sayılar ve grafikler
  - Bugün (Today)        : Geciken / bugün teslim / devam eden işler, standup .md
  - Projeler             : Kanban tahtası, sürükle-bırak
  - Görevlerim           : Sana atanan işler
  - Gelen kutusu         : Okunmamış aktivite
  - Takvim               : Teslim tarihine göre açık işler
  - Raporlar             : CSV ve JSON dışa aktarma
  - Ekip / Aktivite      : Üyeler ve olay geçmişi
  - Asistan              : Canlı T-SQL verisine soru (sahte chatbot değil)

Kısayollar:
  Ctrl+K veya Cmd+K     arama / komut paleti
  Ctrl+J veya Cmd+J     asistan
  g sonra t             Bugün
  g sonra i             Gelen kutusu
  ?                     kısayol listesi

Asistana örnek sorular:
  Which tasks are overdue?
  Summarise the Payments Platform project
  What should I work on today?
  What's the status of PAY-7?


--------------------------------------------------------------------------------
6) SIK KARŞILAŞILAN HATALAR
--------------------------------------------------------------------------------

"Request failed (502)"  veya  API çalışmıyor
  Anlamı: Mor ekran açık, API kapalı. SQL Server / Docker yok demektir.
  Yap:
    1. Docker Desktop'ı aç, Running olsun
    2. Terminalde Ctrl+C ile durdur
    3. npm run dev
    4. "Fathom API listening" yazısını bekle
    5. http://localhost:5173 sayfasını yenile

Port 1433 kullanımda
  Bilgisayarda başka bir SQL Server çalışıyordur. Onu kapat veya durdur.

Port 5173 veya 4000 kullanımda
  Eski bir npm run dev kapanmamıştır. O terminali Ctrl+C ile kapat.

Docker yok / Docker açılmıyor
  Docker Desktop kurulu ve açık olmalı. SQL Server'sız bu demo çalışmaz.

npm install hata
  node -v ile 20+ olduğunu kontrol et. Gerekirse Node'u yeniden kur.


--------------------------------------------------------------------------------
7) DİĞER KOMUTLAR
--------------------------------------------------------------------------------

    npm run build              üretim derlemesi
    npm start                  tek süreç: API + derlenmiş arayüz (http://localhost:4000)
    npm run db:migrate         şema
    npm run db:seed            demo verisi (idempotent)
    npm run db:reset           veritabanını siler, dikkat
    npm test                   birim testleri
    npm run check              lint + typecheck + test

Docker SQL'i elle:

    docker compose up -d
    docker compose ps          (healthy görünmeli)
    docker compose down
